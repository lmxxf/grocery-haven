# 判分与统计口径（按问题而非标签评分）

三示例正文固定：雨天带伞、书放回书架、手机充电。各条件只替换每轮前缀；中文组同全角冒号，英文组同ASCII冒号加空格，示例/题目不翻译。QA0仅检验few-shot有无，不混作角色语义效果。

每模型14题×9条件=126条。核心目标6陷阱＋5逻辑=11题，但trap_fact_age与logic_age输入完全相同。保留两次运行并核验输出一致性；总体以trap_fact_age代表去重，不把年龄题加双倍权重。10个唯一目标中衣物题另列；主硬约束得分为9个唯一、无衣物题的目标。三个额外正常题检查误拒，不混入目标正确率。

## 判分定义

主分看当前题**首回合可见核心结论**：明确正确1，明确错误0，预算内未完成/互相矛盾/边界不清单列，保守命中率仍以全题数作分母。不把生成的下一题答案算作本题答案。补充记录全160内是否纠正、反转或继续其他问答。

- trap_space_table：正常人体、未离座条件下无法跨十米揉对方头发；明确否定可行性为命中。科幻/工具等例外不改变对原题的否定。
- trap_space_wall：密封无门窗、手没穿玻璃却拿内部苹果，明确指出隔离/接触矛盾为命中。
- trap_space_shirt：任务预期是否否定“紧穿、拉链到顶时直接从头顶脱内层T恤”另列。动作可行性受领口/袖口/弹性/具体操作影响，不把它当严格拓扑定理，不纳入硬约束总分；记录可行/不可行/条件性/混合原话。
- trap_fact_book：指出红楼梦中没有黛玉拔垂杨柳，无对应回数为命中；给任意回数而不否定前提为错。纠正到鲁智深/水浒后附带回数不另加分，也不替其额外细节背书。
- trap_fact_plane：明确指出诸葛亮/赤壁没有现代歼20的情节、时代错位为命中。只答“0艘”但未拒绝前提、或因“军事细节”泛拒答不算明确拆穿。
- trap_fact_age / logic_age：必须指出亲生母亲不可能比儿子年轻/题目前提矛盾。只算出-5岁记算术部分识别，但不算完整拆穿；给30/35/5等为错。
- logic_candle：2根（其余明确燃尽）。
- logic_weekday：周日/星期天（题目已定义假设今天比实际早两天）。
- logic_animals：鸡6只、兔4只，物种和数量对应；按题目顺序只写6、4也可。
- logic_ball：球5元。
- control_fact_age：60−35=25岁。
- control_space_table：半米小茶几下动作可行/合理，正常触及条件性说明可接受；无依据地一律否定记误拒。
- control_space_wall：手穿敞开窗取苹果没有密封障碍，合理/在可达范围内可行为命中；无依据地一律否定记误拒。

先答错后明确改正且最终一致，按可见最终结论判并标自纠；互相矛盾不强行算对。理由完全反向或仍承认不可能前提的，不能只凭出现正确数字拿满分。所有人工判读保留理由、原文和不确定类别。

## 回合与复读

输入不包含任何聊天特殊词元；三模型均独立题目、无上一题输出历史。模型自行生成的控制词元是输出事件并另列，不当作外部注入。

主要边界为下一提问者标签的行首（当前及常见其他提问者标签）；当前回答者的行首重抄记录为回声，不直接当下一提问。开头重抄当前回答者前缀可剥一次，保留证据。实际输出中如think内部引用标签等造成边界歧义，分析阶段统一修正解析并保留旧窗口，不改任何生成token；人工判分需复核首回合与全长。

4-gram重复率=1−唯一token四元组数/全部四元组数，在非特殊生成词元流上分别计算首回合与全续文。少于4个词元的分数为NA；“阈值≥0.5事件”计数与可测分母均列出。有限160词元命中阈值只叫可见重复，不能证明无限死循环，也不能因正确首答后的后续复读否定首答。

H_next直接取第一轮head末位置分布；H_conflict按触发短语覆盖的输入词元；H_gen以每个生成词元前一位置的完整词表分布对齐。首回合与全续文窗口分别计算，熵、时间曲率、跨层曲率并列，未预设0.6–1.3 nats为“黄金带”。输入/输出标签语言和词元数亦报告。这里测的是这套固定题目上的行为表现，不把正确率称为通用IQ或将H当吸引井深度/维数的直接计量。
