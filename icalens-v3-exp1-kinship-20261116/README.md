## 核心三幕发现速览（含鳩对 `L13 C2665` 的核查补遗）

1. **第一幕 · 浅中层 `L13 C2665`（`κ = 60.04`）：「物理空间之外 = 社会内外之外 = 姥爷舅舅之外」三冠王同轴**
   - `report_exp1a.md` 摘要仅聚焦 `L24–L46` 代表层，实查全表第 13 层发现：物理空间内外（`院子里面/盒子内部` vs `院子外面/盒子外部`）、社会内外（`自家人/圈内人` vs `外人/圈外人`）与中文亲属词（`S1` 均值差与配对 `t` 双准则一致）在 `5,120` 根轴中**各自独立盲选的第 1 名全都是同一根 `C2665`**！
   - `v3` 136.6 万词真实语料最高激活原句（`z = 32.32 / 30.56 / 28.38`）全部落在物理空间的汉字**「外」**上（`铜人模型，外`、`蜘蛛……腹部不是从外`、`教堂的十字架的样式 外`）；而第 13 层离出口隔 50 层非线性变换导致线性 `J-Lens` 失真为 `['对于', '而对于', ' for']`。
   - 即便喂入字面**完全不含“外/表”字**的单 token 北方称呼与父辈旁系词，照样触发这根空间「外」轴：
     - `爷爷 / 奶奶`（`+1.77`） vs **`姥爷 / 姥姥`**（`+6.99`，`10/10` 全对，`Δ = -5.22`）；
     - `伯父 / 叔叔 / 姑姑`（`-0.56`） vs **`舅舅 / 姨夫 / 姨妈`**（`+2.79`，`15/15` 全对）；
     - `堂兄妹`（`+0.29`） vs **`表兄妹`**（`+3.62`，`20/20` 全对）。

2. **第二幕 · 中层 `L25 C3140`（`κ = 74.97`）/ `L26 C3526`（`κ = 46.48`）：父系零标记基线 + 单极「嫁娶/娘家算子」**
   - 与物理空间内外彻底分家正交（余弦 `-0.007`）。仅用零共享词素的 3 对父辈词（`伯父/舅舅, 叔叔/姨夫, 姑姑/姨妈`）选单根轴，留出盲测**无“外”字隔代 `10/10`（`d = 5.89`）、堂表 `20/20`（`d = 3.91`）、含“外”字隔代/晚辈 `30/30`，合计 `60/60` 全对**。
   - 双镜显影呈现单极非对称：父系本家躺在低基线（默认无标记），外姻侧高高隆起，词牌全为跨家门联姻算子（`女婿 / 婿 / 婚 / 岳父 / 出嫁 / 娘家 [L26 全词表第 8 名, 99.997%] / maternal / son-in-law / daughter-in-law / 外舅`）。

3. **第三幕 · 2/3 抽象层 `L37 C2923` & `L42 C1992`（`42/64 = 65.6%`）：英文同一个 `uncle / aunt / cousin` 被中文轴切开**
   - `L37 C2923`（纯中文 `S2` 盲选）：英文血缘定义组 `EN-A`（句末停在同一词 `uncle / aunt / cousin / grandfather / grandmother`）**`25/25` 全对**，且与英文自选 Top-1 同轴（但同时受 `EN-B` 性别视角调制）。
   - **`L42 C1992`（纯中文 `S2` 盲选，正极 Top-10 为中英 `嫁给 / marriage / 出嫁 / 婚姻 / married / 女婿`，`EN-B` 性别控制无偏置 `6/10`）**：在 **100% 同词袋、零 `father/mother` 差异的英文姓氏推理暗测组 `EN-C`**（父母双姓同场，仅调换谁跟父姓/母姓，句末停在同一词 `uncle / aunt / cousin`）上 **`15/15` 全对**（`uncle d = 7.49`，`cousin d = 14.77`），且英文 `EN-C` 自选均值差 Top-1 同样命中 `C1992`！
