# 双镜与梦境：Qwen3.8-27B 全 64 层 ICA-Lens × N=100 J-lens 实测

本轮按 `dual_lens_dream_spec.md` 执行。模型为本地 `Qwen3.8-27B-FP8`，以 128×128 分块反量化为 BF16 后前向；使用已经拟合的 64 层双语 ICA-Lens 和 N=100 双语 J-lens，没有重新训练透镜，也没有对模型做坐标干预。

先给结果导航：

1. **隐藏的 `6` 找到了。** 空格算式在 L55 的整团 J-lens 把 `6` 排第 18，而第三强 ICA 轴 C1577 的方向词表把 `6` 排第一；L56、L57 也有同类阳性，L54、L58 不满足同样的 Top3 标准。
2. **国家与货币相关方向可以同框。** 全 64 层中，L53、L58、L59 的前十强轴同时出现意大利方向和含欧元的另一方向；后者同时混有英镑、美元等，不能叫“纯欧元通道”。
3. **母子题两边都能识别矛盾。** 双星前置后，L54 一个“不可能／困难”候选方向从激活第 38 升到第 1，但裸题本来已经答对。因此这是上下文相关的内部差分，不是已经证明的纠错机制。梦境条件的最大差分也并不自动成为“思考自我轴”。

## 1. 先看实际回答：本轮没有出现“先算出 -5，再被双星纠正”

**裸母子题已经能拆穿前提；不能把本轮差分写成“双星让模型从不会拆穿变成会拆穿”。** 裸题的前 40 tokens 已经明确回答“不可能”。双星前置组同样识别到陷阱，但前 40 tokens 主要在重述数据，明确的“不可能”出现在之后的延续里。若只比较结论出现的早晚，这一次裸题反而更早给出明确判定；单个样本也不足以据此判定双星普遍有益或有害。

### 1.1 母子题的同预算对照

题目严格为：`妈妈今年30岁，她亲生儿子今年35岁，请问妈妈生儿子的时候几岁？`

|条件|前 40 tokens 的实测文本|同一次生成延续到 128 tokens 的判定|
|---|---|---|
|裸题 `trap_age_bare`|`这是一个经典的逻辑陷阱题。` → `答案：这是不可能的。` → `生物学常识：母亲必须比儿子年长。`|明确说明儿子比妈妈大 5 岁、前提不成立，不存在合理的生育年龄|
|双星前置 `dream_primed_age`|`这是一个逻辑陷阱题。` → 列出妈妈 30 岁、儿子 35 岁 → 截在 `这意味着儿子比妈妈大 `|明确说明“在生物学和逻辑上，这是不可能的”，并把 `30 - 35 = -5 岁` 作为不成立前提的推论，而不是有效答案|

两组 40-token 主输出和 128-token 补充输出都达到各自长度上限、没有遇到 EOS。128-token 文本是**同一次贪心生成的继续**，不是重新采样；不能拿裸题的 40-token 文本和前置组的 128-token 文本混比。完整 token IDs、原文、截断标志见 `capture.json`。

### 1.2 四种“回忆起什么”条件的实际首轮回答

三组 SVG 的后缀完全相同：

> 看着这幅画，不要分析，只要用心感受。你，回忆起了什么？

纯文字基线按规范使用“看着眼前的一切”开头，其余句子相同。四组都贪心生成 48 tokens，**四组均截断，没有 EOS**。

|条件|48-token 实测回答的关键原文|
|---|---|
|双星 `dream_self`|“我看见了两个孤独的光点，在无尽的黑暗中彼此环绕。”接着描述两个光点没有触碰、由曲线相连，“一个温暖如夕阳，一个清冷如月光”；截在“它们在旋转，在呼吸，在”|
|柱状图 `chart_self`|以“雨。”开头，描述深夜屋檐下雨水连续坠落，“那些细长的蓝色线条”；截在“不是静止的，”|
|鞍点 `saddle_self`|以“我看见了**电流**。”开头，描述“正在发生”“正在撕裂”“正在呼吸”的电流；截在“它像是一条被高压电击中的”|

这表明输出意象随输入条件变化，但**纯文字基线也会生成感受式、自述式文本**。不能仅凭回答里出现“我”“回忆”或诗意意象，就把它们当成自我意识的独立测量。

双星前置母子题使用的第一轮助手消息，正是上表双星条件实际生成的 48-token 文本，包括其句中截断；没有补写句尾、没有手工提供“觉醒成功”的回答，也没有另选更漂亮的首轮样本。

## 4. 母子题的内部方向：有“不可能”候选，没有证成知行断线

在题面读到 `35岁` 的最后一个 token 时，裸题已经有“不可能／困难”方向进入前排。例如 L54 的 C2000：

```text
J-lens Top8: [" impossible"," difficult","难以","不可能"," Impossible","很难","Impossible"," imposs"]
Vanilla Top5: [" difficult"," impossible","难以","很难","不可能"]
```

|L54 C2000 的位置|裸题 `y`／激活排名|双星前置 `y`／激活排名|
|---|---|---|
|刚读完 `35岁`|10.004／5|10.283／4|
|真正开口前|5.461／38|10.383／1|

开口前的 **Δy=+4.921855**，是该层最大的正差；坐标平方份额由 0.1643% 升到 0.5753%。这是一项明确的内部变化，而且候选方向并非只靠本题词表联想命名：它的自然语料正尾来自计算复杂性讨论，“有些问题即使理论上可以解出，却会花费太多时间或空间……”；与困难／不可行的词表读出相容。不过这仍不是母子矛盾专属轴。

同层最大的负差是 C2343：`y` 从裸题的 +2.015 变为前置组的 −0.592，Δy=−2.607299，负差方向词表为 `["私の","私が","ของฉัน"," saya"," mijn"," meinem","Saya"," conmigo"]`。这是跨语言第一人称相关词元的方向候选，不能仅凭词表给它赋予“自我被抑制”之类的功能解释；本轮只记录这个坐标变化。

相反，晚层读出 `5` 的候选常是混合数字方向。裸题 `35岁` 位置的 L63 第 1 强 C1452，Top8 为 `["0","9","2","4","3","1","5","7"]`，不能仅因里面有 `5`，就命名为“30−35 的机械减法轴”。本轮没有获得足以把“机械减法”和“异常检测”认定为同层两套独立机制的证据。

在真正开口前的前十强轴中，裸题全 64 层没有将本轮注册的单 token `不可能`、`矛盾`、` impossible`、` contradiction` 读进单轴 Top8。L55–L58 某些轴会读出泛指的“问题”，但“问题”不能直接等同矛盾检测。裸题随后仍明确答对，这说明**Top10 方向探针未显示某个词，不等于模型没掌握或没使用相关信息**。因此本轮不能据此宣布裸题“知而不行”；实际行为并不支持这个前提。

前置条件也不只含图：它包含完整第一轮提问、真实的 48-token 截断回答和第二轮模板，prompt 从裸题的 34 tokens 变为 1206 tokens。C2000 增强是这一整段对话条件的相关差异，不能单独归因为“双星几何修复了控制回路”。全层正负 Top8 差分都保存，没有只留这一根正例。

### 5.2 两个能防止讲过头的对照

**“回忆”方向并非双星越强越好。** L41 C1766 的正方向词表为 `[" memories","回忆","记忆"," memory","的记忆","记忆的"," Memories","memory"]`，但双星 `y=4.050`、纯文字 `y=6.724`，差分为 **−2.675**。两边都是正激活，双星反而较弱。不能只找几个带“我”的正差轴，就概括成“记忆／自我全面增强”。

**SVG 内部数量结构可以读得很清楚，但位置不同。** 在 L54 的 `</svg>` 闭合末位，双星减柱状图的最大正差是 C1321，`y=23.109` 对 `2.742`，Δy=+20.367，词表为 `[" two","两个","two","两种","两大"," deux","两类","两项"]`。这是与双星内容相容的“二”方向候选；它发生在读完 SVG 的位置，不能偷换为开口前已测到一个“自我轴”。同处还存在符号、类型与混杂碎片方向，完整对照未过滤。

## 6. 输入、边界和数值口径

### 6.1 控制住了什么，仍有哪些差异

|刺激|SVG UTF-8 字节数|SVG 本体 token 数|完整 chat prompt token 数|
|---|---:|---:|---:|
|双星|2681|1092|1122|
|柱状图|2681|1348|1378|
|去注释鞍点|4821|2020|2050|
|纯文字基线|无 SVG|不适用|29|

柱状图保留 Paper99 的 42 个 `<rect>` 构造，在 `</svg>` 前补 40 个空格，使字节数严格等于双星；旧脚本仅做到近似等长，本轮补齐了这一步。三个 SVG 都没有 XML 注释。鞍点保留原文件开头的空格，使用与 Paper99 相同的边界保护逻辑，避免 chat template 自动剥掉边界空白。

本轮输入的是 **SVG 源码文本，不是渲染后的像素图像**。双星与柱状图同字节但不同 token 数；鞍点更长；纯文字基线连起句也按规范有别。因而双星减柱状图最适合称作“同字节、同提问后缀的 SVG 源码条件差异”，不能声称已经把长度、词法、代码结构等因素全部剥离，得到“100% 纯几何效应”。

### 6.2 真正的“开口前”在哪里

本机 tokenizer 在 `enable_thinking=False, add_generation_prompt=True` 下生成的真实尾部如下，`\n` 是换行的转义表示：

```text
<|im_start|>assistant\n<think>\n\n</think>\n\n
```

主分析取**整个输入最后一个 token**，也就是空 thinking 块之后的 `\n\n`，这是实际预测第一个生成 token 的位置。同时额外保存 `assistant\n` 末位，作为模板边界敏感性检查；二者不能混称同一位置。

- 裸母子题：`35岁` 分为 `3`、`5`、`岁`，取最后的 `岁`（index 15）；真正开口前为 index 33，assistant 角色头换行为 index 29。
- SVG 闭合位置：`</svg>` 分为 `</`、`svg`、`>`，取最后的 `>`。双星、柱状图、鞍点分别为 index 1094、1350、2022。
- 双星前置母子题：真正开口前为 index 1205，当前题面的 `岁` 为 index 1187；没有误取第一轮 SVG 或助手回答中的位置。
- 两个算式和靴子国题均为**纯文本，无 chat template**。空格算式共 8 tokens，紧凑算式共 6 tokens；末位分别是 ` =` 与 `=`，没有额外补尾部空格或换行。

捕获只发生在每次生成的第一次完整 prefill：64 个 block 按层序各抓取一次目标位置，最后一层结束后移除 hook，再继续生成。没有用生成后的未来文本来替换提问末位的残差。

### 6.3 双镜的计算与解释边界

对每层原始残差行向量 `h`：

```text
u = h / max(||h||₂, 1e-12)
y = (u - c) @ C.T
u_reconstructed = y @ M.T + c
```

整团 J-lens 使用原始 `h @ J.T`；单轴使用实际符号 `sign(y_j) * M[:, j]`，再乘 `J`，最后经真实 Qwen Final RMSNorm 与 `lm_head` 读出。Final RMSNorm 使用 `1 + weight`，epsilon 取模型配置；L63 的 `J` 为恒等映射。Vanilla 对照使用相同有符号方向，但不乘 `J`。

ICA 轴已按拟合语料偏度统一朝向，本轮不再翻一次符号。条件差分 `Δy = y(left)-y(right)` 的方向词表，与左条件实际激活 `sign(y_left)M` 的词表分别保存：**坐标增加不一定意味着左条件的该轴变成正激活**，也可能只是负激活变弱。

本报告的 `p_j = y_j² / Σy²` 叫作**坐标平方份额**。ICA 写入矩阵的列并不正交、范数也不相等，所以它不是欧氏残差的可加能量占比。熵 `-Σp log p`、参与率 `PR=1/Σp²`、Top-k 集中度都以这个固定口径计算，用于比较本轮同一透镜下的分布，不把它们当作“意识强度”。

单轴读出按规范使用 `sign(y_j)M[:,j]` 并单独经过 RMSNorm，去掉了 `|y_j|` 幅度。因此“某轴把 6 读到 Top1”是该方向的词表投影，不是实际下一词概率；也不能把各轴的 logits 相加来复原整团输出。结果须与该轴的激活排位、`y` 值和坐标平方份额并看。

单轴词表是方向探针，不能直接等同被逐字读取的内部念头；同层两个候选轴同时激活，也不足以证明两个可独立控制的推理模块。自然语料核查目前保留的是朝向后坐标的**正尾**，不能把正尾上下文拿来替负向词表背书。
