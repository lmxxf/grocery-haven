## 核心四大发现速览（含鳩的全空间无监督 `z(奴才) - z(臣)` 补遗）

### 1. 《出师表》“先帝不以臣卑鄙”去现代污染校准尺：长纯文言完胜英文隔离舱，中深层自动洗净现代贬义
- **层间两阶段去噪**：在浅中层（如 `L16 C1821` 罪恶贬义轴），即便左铺两千字《三国志》纯文言（`W2`），模型刚读到 `["卑", "鄙"]` 仍会激起 `35.6%`（短句 `W0` 为 `42.4%`）的字面现代贬义本底；但进入中深层概念区后，长文言流形将现代道德贬义彻底压平：
  - `L30 C846`（现代卑鄙泛化 `8/8`，正极 `crap / horrible / stupid / 侮辱 / 劣`）：`W2` 残留低至 **`-0.43%`**（`卑鄙 = +4.05` vs 同位替换 `微贱/浅陋/愚钝 = +4.13`）；
  - `L41 C1726`：短句 `W0` 尚有 `28.3%` 现代贬义残留，套上《出师表》前文 `W1` / 《三国志》长卷 `W2` 后暴跌至 **`1.5% / 6.0%`**（消除最高 `94.7%`）；`L38`（`-4.8%`）、`L45`（`-1.9%`）同样跨零洗净。
- **为什么纯英文隔离舱 `W3a` 反而不如长古文 `W2`**：38 个有效层中位残留 **`W2`（千字《三国志》 `17.0%`） < `W1`（百字《出师表》 `19.6%`） < `W0`（短句 `21.0%`） < `W3a`（纯英文导语+短句 `25.6%`）**。英文切断中文语境后突然蹦出短句汉字，模型默认落入占比 99% 的现代白话词表入口；唯有同源长文言助跑才能把残差流稳稳送入古汉语轨道。

### 2. 全空间无监督盲搜 `z(奴才) - z(臣)`：一举照穿浅层「家奴字根闪念」与深层「雍正“称臣得体”的制度几何」
在 10 份真实清代奏折原长文下，仅将 **`臣` 替换为 `奴才`**，不预设任何外源词表，直接在全 `5,120` 根 ICA 轴中盲搜 `≥9/10` 符号一致的最大位移轴：
- **浅中层 `L18`——字根层面的「奴隶 / Slave」一闪念确实存在！**

- **中层 `L25–L32`——丢失的不是道德清白，而是「宰辅 / 封疆大臣（Governor）」的外朝公器体统！**
  - 到中层，`Slave` 字根闪念消退，但在 `10/10` 一致负向暴跌的轴上整齐亮出：
    - `L25 C2108`（`Δ = -7.52`）：`['请示', '献策', '提案', '申告']`（语料：*“姜维启**奏**”*）；
    - **`L25 C1146`（`Δ = -5.70, 10/10`）**：**`['大臣', '分管', '侍郎', '大夫', ' counsel', '宰相', '吏', '政务']`**（语料：*“唐朝**宰相**”*）；

### 4. 《红楼梦》日常自称“奴才”的语法真身：纯粹的第一人称代词「我（`myself / I`）」
- 在《红楼梦》原著内部无监督对比“主子痛骂奴才（`B`）”与“管家包衣回话自称奴才（`A2`）”，留出集 `9/9`（100%）切开的冠军轴（`L29 C502 / L35 C416 / L42 C368 / L45 C523 / L48 C335`）连续二十层清一色全都是 **`[' myself', ' my', '我自己', '我的', ' I', '我']` 第一人称自指轴**（林之孝、平儿、李贵自称时高达 `+13.35 ~ +16.84`，挨骂时跌回 `+1.17`）。在康雍乾旗人与包衣日常语感中，平静的“奴才”在中深层已完全代词化为一个制度性的“我”。
